# /ETF分析

## 功能
调用4个分析skill（指数分析/估值分析/技术分析/资金面分析），读取报告，交叉验证，形成变异认知，输出概率加权的ETF投资建议。

## 输入
ETF代码（如 510300）

## 执行步骤

### Step 0：判断ETF类型
- 确定ETF简称和全称（通过搜索ETF代码）
- 判断ETF类型：宽基 / 行业 / 主题 / 策略 / 跨境 / 债券 / 商品
- 确定跟踪指数及代码
- 确定每个分析skill的可用维度
- 创建输出文件夹：`分析记录/{ETF简称}_{代码}/`

### Step 1：并行调用分析skill
使用 Agent 工具并行调用4个分析skill，每个agent将报告写入对应路径。

| Agent | Skill文件 | 输出文件 |
|-------|----------|----------|
| 指数分析 | skills/指数分析.md | 01_指数分析.md |
| ETF估值分析 | skills/ETF估值分析.md | 02_ETF估值分析.md |
| 技术分析 | skills/技术分析.md | 03_技术分析.md |
| ETF资金面分析 | skills/ETF资金面分析.md | 04_ETF资金面分析.md |

### Step 2：读取报告 + 数据完整度评分
读取4份报告，汇总哪些维度完整、哪些标注了"不适用"。评分：完整 / 基本完整 / 部分缺失 / 严重缺失。

### Step 3：提炼变异认知
从4份报告中提取市场共识 vs 我们的不同看法（至少一个），引用具体数据作为证据。找不到变异认知 → 写"不建议买入"。

ETF常见变异认知来源：
- 市场认为估值合理，但我们发现PE分位处于极端低位 + 盈利开始上修
- 市场恐慌抛售，但份额逆势增长说明资金在低吸
- 市场追捧某行业ETF，但估值分位已>90% + 机构在减仓

### Step 4：估值分位 + 资金方向 → 仓位建议

ETF仓位逻辑与个股不同：**个股看确信度×安全边际，ETF看估值分位+资金方向+ETF类型**。

#### 第一步：确定仓位基准

| ETF类型 | 最大仓位 | 角色 | 说明 |
|------|:--:|------|------|
| 宽基ETF（沪深300/中证500/科创50等） | 20% | 核心仓位 | 长期配置底仓 |
| 行业ETF（券商/医药/消费等） | 10% | 卫星仓位 | 行业轮动 |
| 主题ETF（AI/新能源/碳中和等） | 5% | 投机仓位 | 主题催化剂驱动 |
| 策略ETF（红利/低波/质量等） | 10% | 风格仓位 | 因子暴露 |
| 跨境ETF（纳指/恒生/标普等） | 15% | 核心/卫星 | 全球配置 |
| 债券ETF | 15% | 防御仓位 | 降低波动 |
| 商品ETF（黄金/原油等） | 5% | 对冲仓位 | 通胀/尾部风险对冲 |

#### 第二步：根据估值分位调整

| 估值分位 | 仓位调整 | 说明 |
|------|:--:|------|
| <20% | ×1.2~1.5 | 极度低估，可超配 |
| 20-40% | ×1.0~1.2 | 偏低，标配偏重 |
| 40-60% | ×1.0 | 合理，标准配置 |
| 60-80% | ×0.5~0.8 | 偏高，减配 |
| 80-90% | ×0.3~0.5 | 高估，仅观察仓 |
| >90% | ×0 | 极度高估，清仓/不买 |

#### 第三步：根据资金方向微调

| 份额方向 | 折溢价 | 调整 |
|------|:--:|:--:|
| 持续增长 + 溢价 | 积极 | +10%仓位 |
| 持续增长 + 平价 | 正面 | +5%仓位 |
| 震荡 | 平价 | 不变 |
| 持续缩减 + 折价 | 负面 | -10%仓位 |
| 份额缩减 + 净值涨 | 警惕 | -15%仓位（出货信号） |

#### 第四步：综合计算

```
建议仓位 = 类型基准 × 估值调整系数 × (1 + 资金调整比例)

示例：
  沪深300ETF(基准15%) + PE分位25%(估值×1.2) + 份额增长溢价(资金+10%)
  = 15% × 1.2 × 1.10 = 19.8%
  → 实际建议：18-20%（上限20%）
```

### Step 5：制定操作计划
- 判断当前是否可买、什么价格区间
- ETF优先考虑**定投策略**：分几期、每期间隔多久
- 如果等，等什么信号（如PE分位跌破20%、份额开始止跌回升）
- 定投 vs 一次性买入的判断：
  - 估值分位<20% → 可一次性买入50%目标仓位，剩余分批
  - 估值分位20-50% → 标准定投，分3-6期
  - 估值分位>50% → 等待更好时机，或极小仓位定投

### Step 6：写完整决策报告

## 引用规范（写报告前逐项检查）
报告中所有数据点均须标注来源编号（如[1][2]），报告末尾附完整出处表。格式遵循项目 CLAUDE.md 引用规范。

**写完后必须逐条检查（共3项）：**
1. [ ] 报告中每个数字/论断后都有 `[n]` 标注
2. [ ] 参考文献表中**每条都有** `[文档名](URL)` 格式的超链接（不许出现纯文本无链接的条目）
3. [ ] 每个URL都是可访问的完整链接，不是网站首页

**自动校验**：报告写完后，必须运行 `python tools/check_citations.py <报告路径>` 验证。校验不通过 → 修复后重新校验，直到通过为止。

出处优先级：法定披露 > 金融平台 > 第三方估计。
