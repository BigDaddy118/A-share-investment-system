# /技术分析

## 功能
分析K线趋势、关键技术位、量价关系和技术指标，判断当前处于什么位置、买方还是卖方掌控、什么信号出现时趋势可能改变。

## 适用范围
✅ A股全市场（K线和量价数据公开可查）

## 输入
股票代码 + 公司简称 + 当前股价

## 执行步骤

### Step 1：K线趋势判断
- 当前处于什么趋势？（上升/下降/横盘）
- 近1月涨跌幅？近3月？年初至今？
- 距52周高/低点的位置？
- 是否处于历史新高/新低附近？

### Step 2：关键技术位
- 支撑位1、支撑位2（前期低点、筹码密集区、均线）
- 压力位1、压力位2（前期高点、套牢盘密集区、均线）
- 当前价离支撑位近还是压力位近？（判断风险收益比）

### Step 3：量价关系
- 近期成交量趋势（放量/缩量）
- 量价配合情况（价涨量增=健康，价涨量缩=警惕）
- 有无异常放量？（单日成交量>5日均量2倍）

### Step 4：技术指标
- 均线排列：MA5/MA10/MA20/MA60 多头/空头/缠绕
- MACD：零轴上方/下方？金叉/死叉？红柱/绿柱趋势？
- KDJ：数值，超买区（>80）/超卖区（<20）
- RSI：数值，超买（>70）/超卖（<30）

### Step 5：综合判断
各指标信号汇总，给出：买入 / 等待 / 回避

### Step 6：标注来源
报告中所有数据点必须标注来源编号（格式遵循项目 CLAUDE.md 引用规范）：
- 每个价格/指标数值后用 `[1]` `[2]` 标注出处编号
- 每个表格下方注明来源编号
- 报告末尾列出编号对应的完整出处
- ⚠️ 写完后逐条检查：(1)每个数字都有[n] (2)参考文献每条都是 `[文档名](URL)` 超链接 (3)URL是具体页面非首页
- ✅ 报告写完后，必须运行 `python tools/check_citations.py <报告路径>` 校验，不通过则修复后重跑

### Step 7：写报告
