# /财报分析

## 功能
读取上市公司年报/季报原文，提取核心财务数据，评估利润真实性、现金流质量和资产负债表健康度。

## 适用范围
✅ A股全部上市公司（年报/季报公开披露）
数据来源：新浪财经、中财网的年报原文（curl可获取，需处理GB2312→UTF-8编码）

## 输入
股票代码（如 600030）+ 公司简称（如 中信证券）

## 执行步骤

### Step 1：获取一手数据
搜索并下载最新年报+最新季报原文，提取以下数据：

**利润表（近3年+最新季报）：**
- 营业收入、营收增速
- 归母净利润、扣非净利润（两者对比，差异>10%需解释）
- 毛利率（连续3年趋势）
- 净利率（连续3年趋势）
- 研发费用资本化率（如有，>30%需标注红旗）

**资产负债表（最新报告期）：**
- 总资产、归母净资产
- 资产负债率
- 商誉 / 净资产（>30% → 红旗）
- 有息负债 / 净资产
- 短期借款 / 货币资金（>1 → 流动性红旗）
- 大股东质押比例（>50% → 红旗）
- 应收账款 / 营收（同比趋势，增速>营收增速 → 红旗）
- 存货 / 营收（同比趋势，增速>营收增速 → 红旗）

**现金流量表（近3年）：**
- 经营现金流 / 净利润（<0.8连续2年 → 红旗）
- 资本开支 / 经营现金流
- 自由现金流 = 经营现金流 - 资本开支

**审计与合规：**
- 审计机构名称
- 审计意见类型（非标 → 严重红旗）
- 近3年是否被证监会立案/处罚

### Step 2：杜邦拆解
```
ROE = 净利率 × 资产周转率 × 杠杆倍数

近3年拆解：
         TTM    去年    前年
ROE      ___%   ___%   ___%
净利率    ___%   ___%   ___%
周转率    ___    ___    ___
杠杆      ___x   ___x   ___x
```
判断：ROE的驱动力是什么？高杠杆驱动的ROE质量不如高利润率驱动的ROE。

### Step 3：识别红旗
逐项检查，有红旗必须写入报告：
- [ ] 审计非标意见
- [ ] 扣非净利润与归母净利润差异>20%
- [ ] 经营现金流/净利润 <0.5（连续2年）
- [ ] 应收账款增速 > 营收增速（连续2年）
- [ ] 存货增速 > 营收增速（连续2年）
- [ ] 研发费用资本化率 >30%
- [ ] 商誉/净资产 >50%
- [ ] 大股东质押 >70%
- [ ] 短期借款 > 货币资金
- [ ] 近3年被证监会立案/处罚

### Step 4：标注来源
报告中所有数据点必须标注来源编号（格式遵循项目 CLAUDE.md 引用规范）：
- 每个数字/论断后用 `[1]` `[2]` 标注出处编号
- 每个表格下方注明来源编号
- 报告末尾列出编号对应的完整出处（来源机构、文档名、日期、URL，URL为必填）
- ⚠️ 写完后逐条检查：(1)每个数字都有[n] (2)参考文献每条都是 `[文档名](URL)` 超链接 (3)URL是具体页面非首页
- ✅ 报告写完后，必须运行 `python tools/check_citations.py <报告路径>` 校验，不通过则修复后重跑

### Step 5：写报告
