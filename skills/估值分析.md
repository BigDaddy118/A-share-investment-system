# /估值分析

## 功能
通过反向DCF和三情景概率加权，判断当前股价隐含的预期是否合理，估算概率加权预期回报。

## 适用范围
✅ 沪深300：卖方一致预期完整，可做完整三情景
⚠️ 中证500：部分覆盖，只做反向DCF + 历史分位
❌ 其余：无一致预期，只做反向DCF + 历史分位

## 输入
股票代码 + 公司简称 + 当前股价（如有年报EPS可直接算PE）

## 执行步骤

### Step 1：获取估值数据
- 当前股价、市值、PE(TTM)、PB、股息率
- 3年历史PE/PB分位数（最高/中位/最低）
- 卖方一致预期（如有）：未来2-3年EPS、净利润、目标价、评级分布
- 可比公司PE/PB/ROE（2-3家）

### Step 2：反向DCF（必做）
```
当前市值：____亿
假设WACC=10%，终值PE=15x

当前股价隐含的3年FCF增速：____%
我们预期的合理增速：____%
```
判断：隐含增速 < 预期增速 → 有安全边际。

### Step 3：三情景概率加权（有数据时做，无数据时跳过）
熊/基/牛情景，每情景赋值：
- 触发条件
- 3年净利润CAGR
- 3年后合理PE
- 3年后市值
- 含分红总回报 → 年化回报

概率加权年化 = P(熊)×R(熊) + P(基)×R(基) + P(牛)×R(牛)

### Step 4：可比估值验证
与同行对比PE/PB/ROE，判断折价/溢价能否用基本面差异解释。

### Step 5：标注来源
报告中所有数据点必须标注来源编号（格式遵循项目 CLAUDE.md 引用规范）：
- 每个估值数据/预测数字后用 `[1]` `[2]` 标注出处编号
- 每个表格下方注明来源编号
- 报告末尾列出编号对应的完整出处
- ⚠️ 写完后逐条检查：(1)每个数字都有[n] (2)参考文献每条都是 `[文档名](URL)` 超链接 (3)URL是具体页面非首页
- ✅ 报告写完后，必须运行 `python tools/check_citations.py <报告路径>` 校验，不通过则修复后重跑

### Step 6：写报告

## 附录：数据获取指南（供分析时参考，不写入最终报告）

### 估值基础数据
| 来源 | 内容 | 获取方式 |
|------|------|----------|
| **东方财富Choice** | PE/PB/PS当前值及历史分位数、EPS一致预期、评级分布 | 网页搜索+API |
| **同花顺iFinD** | 一致预期（24-27家机构）、目标价、盈利预测明细 | 网页搜索 |
| **富途牛牛** | PE(TTM)、PB(MRQ)、股息率（实时更新） | curl + 网页解析 |
| **Yahoo Finance** | 港股/美股对标估值（如有H股/ADR） | curl（免费API） |

### 一致预期与卖方覆盖
| 来源 | 内容 | 获取方式 |
|------|------|----------|
| **朝阳永续Go-Goal** (go-goal.com) | 最权威的一致预期数据（买方可直接引用），加权算法考虑分析师历史准确度 | 需要订阅（买方可直接从终端引用） |
| **慧博投研** (hibor.com.cn) | 全市场券商研报聚合，每日更新10,000+份 | 网页搜索，基础功能免费 |
| **东方财富研报中心** | 券商研报摘要、评级变化、目标价调整 | curl（data.eastmoney.com/report） |
| **中证指数有限公司** (csindex.com.cn) | 沪深300/中证500等指数PE/PB/股息率（全市场估值水位参考） | curl（免费公开） |

### DCF/WACC参数来源
| 参数 | 来源 | 说明 |
|------|------|------|
| **无风险利率** | 中国货币网/中国债券信息网 | 10年期国债收益率（chinamoney.com.cn / chinabond.com.cn） |
| **股权风险溢价** | 中证指数/学术文献（CSMAR隐含ERP） | A股历史ERP约4-6% |
| **Beta** | 东方财富/同花顺 | 个股相对于沪深300的Beta系数 |
| **行业WACC参考** | 券商研报 | 卖方通常给出WACC假设（8-12%） |
| **债券收益率曲线** | 中国债券信息网 (chinabond.com.cn) | 3,800+条曲线，用于不同期限贴现 |

### 历史分位与可比估值
| 来源 | 内容 | 获取方式 |
|------|------|----------|
| **理杏仁** (lixinger.com) | PE/PB历史分位数（可选5/10/全历史区间） | 网页（有免费额度） |
| **Wind/Choice PB Band图** | 股价叠加历史PB通道，直观判断估值水位 | 券商研报中频繁引用，可从研报截图获取 |
| **可比公司PE/PB/ROE** | 东方财富行业板块对比表 | curl + 网页解析 |
