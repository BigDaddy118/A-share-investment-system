# /审视持仓

## 功能
加载历史投资决策报告，复查论据是否仍然成立，输出"继续持有 / 减仓 / 清仓"的操作建议。

## 输入
股票代码（如 600030）

## 前置条件
该标的已通过 /投资决策 生成过 `00_投资决策.md`。

## 执行步骤

### Step 1：读取历史决策报告
读取 `分析记录/{公司简称}_{股票代码}/00_投资决策.md`，提取：
- 原始的论据和核心假设
- 论据推翻条件
- 建仓价格和仓位

### Step 2：复查核心假设
逐项检查原始假设是否仍然成立：
- 财报层面：最新季报ROE/毛利率/现金流是否恶化？
- 商业层面：护城河有无结构性裂缝？管理层有无减持？
- 估值层面：当前PE/PB是否已超出合理范围？
- 催化剂层面：催化剂发生了吗？市场反应如何？
- 资金层面：主力/北向/机构在加仓还是减仓？

### Step 3：判断
- 论据完好，假设全部成立 → ✅ 继续持有
- 论据部分受损，1-2个假设松动 → ⚠️ 减仓（说明比例和原因）
- 论据被推翻，核心假设不成立 → 🔴 清仓（说明原因）
- 情况不明确 → 诚实说，建议等待进一步信息

### Step 4：输出操作建议

引用规范：报告中引用的数据点和原始论据须标注来源编号（如引用原00_投资决策.md中的[1]号出处，或新增数据标注新来源）。

## 输出
直接向用户输出操作建议（不写文件），格式：

## {公司简称} ({股票代码}) — 持仓复查

### 原始论据
（引用00_投资决策.md中的论据，标注原始出处编号）

### 核心假设复查

| 假设 | 状态 | 证据 |
|------|:--:|------|
| | ✅/⚠️/🔴 | （证据标注来源编号） |

### 结论
**{继续持有 / 减仓至X% / 清仓}**

### 理由
（一段话说明为什么，引用具体数据来源）
