# /公司治理穿透

## 功能
检查公司治理层面的红旗信号——股权质押、关联交易、增减持、限售股解禁、独董质量、审计意见、监管处罚、股权激励和分红记录。机构投资者在重仓前都会做这层穿透检查。

## 适用范围
✅ A股全市场（质押/增减持/解禁/审计/监管数据公开可查）
⚠️ 部分数据依赖年报/季报披露（关联交易明细、独董出席）
⚠️ 监管问询函需通过交易所网站查询

## 输入
股票代码 + 公司简称

## 执行步骤

### Step 1：大股东股权质押
- 第一大股东及其一致行动人持股比例
- 大股东质押股数 / 大股东持股数（质押比例）
  - <30% → 安全 | 30-50% → 关注 | 50-80% → 红旗 | >80% → **严重红旗**
- 整体质押比例（全市场质押股数 / 总股本）
- 近期质押是增加还是减少？
- 是否存在质押平仓风险？（股价距平仓线多远）

### Step 2：关联交易
- 近1年关联交易总额 / 营业收入
  - <5% → 正常 | 5-15% → 关注 | 15-30% → 黄色红旗 | >30% → **红旗**
- 关联交易类型（采购/销售/担保/资金拆借/资产转让）
- 是否存在向大股东输送利益的可疑交易？（如高价收购大股东资产）
- 是否有大股东占用上市公司资金？

### Step 3：大股东/高管增减持
- 近1年大股东增减持记录（次数、金额、方向）
  - 增持 → 积极信号
  - 减持 → 红旗（尤其是大额减持、频繁减持）
- 近1年董监高增减持记录
  - 多名高管同时减持 → 严重红旗
- 是否有减持预披露公告？（未来3个月计划减持量）

### Step 4：限售股解禁
- 未来3个月/6个月/12个月的解禁时间表
- 解禁股数 / 流通股数
  - <5% → 影响小 | 5-15% → 中等 | 15-30% → 较大 | >30% → 重大冲击
- 解禁股东是谁？（大股东/机构/定增对象/员工持股）
- 大股东解禁后是否有减持意愿？（结合过往减持记录判断）

### Step 5：独立董事与董事会
- 独董占董事会比例（≥1/3是法定底线）
- 独董年度出席率（<80% → 红旗）
- 是否有独董对董事会议案提出异议/弃权？
- 独董背景和专业能力（有没有"花瓶独董"？）
- 董事长与总经理是否同一人？（两职合一增加代理风险）

### Step 6：审计意见
- 近3年审计意见类型：
  - 标准无保留意见 → 正常
  - 带强调事项段的无保留意见 → 关注（如持续经营能力存疑）
  - 保留意见 → 红旗
  - 否定意见/无法表示意见 → **严重红旗，直接不建议买入**
- 审计机构是否更换频繁？（3年内换2次以上 → 红旗）
- 审计机构是否为"四大"或国内头部所？（非头部+频繁更换=更大风险）

### Step 7：监管处罚与问询
- 近3年证监会/交易所行政处罚记录
- 近1年交易所问询函及回复情况
  - 是否多次被问询？回复是否及时？回复质量如何？
- 是否有立案调查？
- 是否曾被ST/*ST？

### Step 8：股权激励
- 是否有股权激励计划？行权条件是什么？
- 行权条件是否过于宽松？（如净利润增速门槛仅5%）
- 股权激励摊销费用对利润的影响多大？
- 激励对象范围是否合理？（仅覆盖高管=变相福利）

### Step 9：分红记录
- 连续分红年数
- 近3年分红率（分红/净利润）均值及稳定性
- 是否有"突击高分红"配合大股东减持的嫌疑？
- 分红率 < 10% + 无合理理由（如高成长再投资）→ 关注

### Step 10：综合治理评级
综合以上9项，给出治理评级：

| 评级 | 条件 |
|:--:|------|
| **优秀** | 无红旗，分红稳定，独董出席率100%，审计标准无保留 |
| **良好** | 1-2个关注项，无红旗 |
| **一般** | 1个黄色红旗或多项关注 |
| **有瑕疵** | 1个红色红旗（如质押50-80%或关联交易>30%） |
| **严重红旗** | 质押>80% / 审计非标 / 立案调查 / 多名高管集体减持 |

> **规则**：
> - 严重红旗 → **不建议买入**（不管其他维度多好）
> - 有瑕疵 → 确信度下调一档，仓位上限减半
> - 一般 → 正常流程，注明关注事项即可

### Step 11：标注来源
报告中所有数据点必须标注来源编号（格式遵循项目 CLAUDE.md 引用规范）：
- 每个数据后用 `[1]` `[2]` 标注出处编号
- 每个表格下方注明来源编号
- 报告末尾列出编号对应的完整出处
- ⚠️ 写完后逐条检查：(1)每个数字都有[n] (2)参考文献每条都是 `[文档名](URL)` 超链接 (3)URL是具体页面非首页
- ✅ 报告写完后，必须运行 `python tools/check_citations.py <报告路径>` 校验，不通过则修复后重跑

### Step 12：写报告
