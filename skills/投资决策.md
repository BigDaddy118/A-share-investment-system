# /投资决策

## 功能
调用全部6个分析skill，读取报告，交叉验证，形成变异认知，输出概率加权的投资建议。

## 输入
股票代码（如 600030）

## 执行步骤

### Step 0：宏观环境确认 + 判断可分析深度
- **先读取 `分析记录/宏观环境诊断.md`**（如存在），确认当前宏观象限和行业偏好
- 该标的所处行业是否为宏观环境偏好的方向？
- 宏观逆风时，最大仓位上限自动下调（如重仓25%→标准偏重15%）
- 宏观顺风+行业超配 → 仓位可触及上限
- 确定公司简称（通过搜索股票代码）
- 判断成分股归属：沪深300 / 中证500 / 其他
- 确定每个分析skill的可用维度
- 创建输出文件夹：`分析记录/{公司简称}_{股票代码}/`

### Step 1：并行调用分析skill
使用 Agent 工具并行调用6个分析skill，每个agent将报告写入对应路径。

### Step 2：读取报告 + 数据完整度评分
读取6份报告，汇总哪些维度完整、哪些标注了"不适用"。评分：完整 / 基本完整 / 部分缺失 / 严重缺失。

### Step 3：提炼变异认知
从6份报告中提取市场共识 vs 我们的不同看法（至少一个），引用具体数据作为证据。找不到变异认知 → 写"不建议买入"。

### Step 4：概率加权 → 仓位建议

确信度：
- 高确信：变异认知清晰 + 证据充分 + 数据完整
- 中确信：变异认知存在 + 证据部分支持
- 低确信：变异认知模糊 + 证据不足

| 确信 × 安全边际 | 仓位建议 |
|------|------|
| 高确信 + 安全边际大 + 催化剂临近 | 重仓（15-25%） |
| 高确信 + 安全边际大 + 催化剂较远 | 标准偏重（10-15%） |
| 高确信 + 安全边际一般 | 标准仓（8-12%） |
| 中确信 + 安全边际大 | 中等仓（5-8%） |
| 中确信 + 安全边际一般 | 观察仓（3-5%） |
| 低确信 或 安全边际不足 | 不买 |

数据缺失 → 确信度下调一档。
宏观环境对该行业不利 → 仓位上限降一档（如重仓→标准偏重，标准→中等）
宏观环境对该行业有利 → 仓位可触及上限，不做下调

### Step 5：制定操作计划
判断当前是否可买、分几批、什么条件、什么价格区间。如果等，等什么信号。

### Step 6：写完整决策报告

## 引用规范（写报告前逐项检查）
报告中所有数据点均须标注来源编号（如[1][2]），报告末尾附完整出处表。格式遵循项目 CLAUDE.md 引用规范。

**写完后必须逐条检查（共3项）：**
1. [ ] 报告中每个数字/论断后都有 `[n]` 标注
2. [ ] 参考文献表中**每条都有** `[文档名](URL)` 格式的超链接（不许出现纯文本无链接的条目）
3. [ ] 每个URL都是可访问的完整链接，不是网站首页

**自动校验**：报告写完后，必须运行 `python tools/check_citations.py <报告路径>` 验证。校验不通过 → 修复后重新校验，直到通过为止。

出处优先级：法定披露 > 金融平台 > 第三方估计。

## 输出文件
`分析记录/{公司简称}_{股票代码}/00_投资决策.md`
