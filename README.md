# A-Share Investment Analysis System

A股机构级投资分析技能系统。自上而下：宏观定调 → 资产配置 → 行业偏好 → 个股/ETF精选 → 组合管理。

## 使用的模型

系统运行在 [Claude Code](https://claude.ai/code) 平台上，利用其 Agent 工具架构实现多代理并行分析。

| 层级 | 任务 | 使用模型 |
|------|------|----------|
| **编排层** | `/投资决策` `/ETF分析` `/组合诊断` `/审视持仓` | **DeepSeek V4 Pro** |
| **分析层** | 全部 13 个分析 Agent | **DeepSeek V4 Pro** |
| **顶层** | `/宏观诊断` | **DeepSeek V4 Pro** |

系统不绑定特定模型，可在 Claude Code 配置中切换 DeepSeek / Claude / 其他模型提供商。

## 快速开始

### 前置条件

- [Claude Code](https://claude.ai/code)
- 网络连接（分析过程中抓取公开财务数据）
- Python 3.x（用于 `check_citations.py` 引用校验）

### 安装

```bash
git clone git@github.com:BigDaddy118/A-share-investment-system.git
cd A-share-investment-system
```

### 使用

```bash
/宏观诊断                  # 先判断宏观象限 → 资产配置 + 行业偏好

/投资决策 600030           # 个股：8维度并行分析 → 决策报告
/审视持仓 600030           # 复查已有持仓的论据是否成立

/ETF分析 510300            # ETF：5维度并行分析 → 决策报告

/组合诊断                  # 组合层面集中度/相关性/风险评估
```

## 分析流程

### 自上而下

```
/宏观诊断                       ← 宏观象限 → 资产配置 → 风格/行业偏好
  ↓
/投资决策 或 /ETF分析            ← 标的分析（仓位受宏观约束）
  ↓
/组合诊断                       ← 集中度 / 相关性 / 风险暴露
```

### 个股：8 维度并行

```
/投资决策 600030
  │
  ├─ Step 0: 读取宏观诊断 → 确认行业方向
  ├─ Step 1: 8 个 Agent 并行分析
  │   ├── 01_财报分析.md
  │   ├── 02_商业分析.md
  │   ├── 03_估值分析.md
  │   ├── 04_催化剂分析.md
  │   ├── 05_技术分析.md
  │   ├── 06_资金面分析.md
  │   ├── 07_同行对比.md          ← 同行业ROE/增速/估值排名
  │   └── 08_公司治理穿透.md      ← 质押/关联交易/审计/增减持
  │
  ├─ 变异认知 → 确信度（宏观+治理+同行排名调整）
  ├─ 概率加权 → 仓位建议
  └─ 00_投资决策.md → check_citations.py 校验
```

### ETF：5 维度并行

```
/ETF分析 510300
  │
  ├─ Step 0: 读取宏观诊断
  ├─ Step 1: 5 个 Agent 并行分析
  │   ├── 01_指数分析.md
  │   ├── 02_ETF估值分析.md
  │   ├── 03_技术分析.md           ← 复用个股技术分析skill
  │   ├── 04_ETF资金面分析.md
  │   └── 05_ETF产品分析.md        ← 跟踪误差/费率/Amivest/同指数排名
  │
  ├─ 估值分位 + 资金方向 + 产品品质 → 仓位建议
  └─ 00_ETF决策.md → check_citations.py 校验
```

## 仓位逻辑差异

| | 个股 | ETF |
|------|------|------|
| **核心驱动** | 确信度 × 安全边际 | 估值分位 + 资金方向 + 产品品质 |
| **调整因素** | 宏观环境 + 公司治理 + 同行排名 | 宏观环境 + 产品品质 + 同类排名 |
| **一票否决** | 质押>80% / 审计非标 / 立案调查 | 跟踪误差>2% / 清盘风险 |
| **买入策略** | 分批建仓（催化剂验证后加仓） | 优先定投（估值分位决定节奏） |

## 投资方法论

1. **自上而下**：先宏观定调，后选标的。宏观逆风时仓位自动降档
2. **同行对比**：必须横向排名，排名末位需充分解释"为什么还选它"
3. **治理排除**：公司治理严重红旗 → 直接否决，不看其他维度
4. **变异认知驱动**：每笔投资必须找到"市场共识 vs 我们不同看法"
5. **论据可推翻**：每笔投资预定义清仓条件，触发即执行

## 引用标准

所有报告采用学术论文级引用规范：每个数据点标注 `[n]`，参考文献均为可点击的 `[文档名](URL)` 超链接。报告生成后自动运行 `check_citations.py` 校验。
