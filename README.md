# A-Share Investment Analysis System

A股机构级投资分析技能系统。通过 6 维度并行分析 + 变异认知提炼 + 概率加权仓位计算，对任意 A 股标的生成完整的投资决策报告。

## 使用的模型

系统运行在 [Claude Code](https://claude.ai/code) 平台上，利用其 Agent 工具架构实现多代理并行分析。当前使用的模型：

| 层级 | 任务 | 使用模型 | 说明 |
|------|------|----------|------|
| **编排层** | `/投资决策` 交叉验证、变异认知、仓位计算 | **DeepSeek V4 Pro** | 需要深度推理和综合判断 |
| **编排层** | `/组合诊断` 集中度/相关性/风险评估 | **DeepSeek V4 Pro** | 组合层面需要全局视角 |
| **编排层** | `/审视持仓` 论据复查 | **DeepSeek V4 Pro** | 单标的复查，推理量中等 |
| **分析层** | 6 个分析 Agent（财报/商业/估值/催化剂/技术/资金面） | **DeepSeek V4 Pro** | 数据抓取 + 结构化分析 + 信号判断 |

### 模型配置

系统不绑定特定模型。通过 Claude Code 的模型设置，可以灵活切换：

- **DeepSeek** 系列：deepseek-v4-pro、deepseek-v3 等
- **Claude** 系列：claude-opus-4-7、claude-sonnet-4-6、claude-haiku-4-5 等
- 其他 Claude Code 兼容的模型提供商

具体在 Claude Code 配置中修改 `model` 字段即可切换。不同层级的 Agent 也可以通过 `model` 参数指定不同模型，在成本和效果之间平衡。

## 快速开始

### 前置条件

- 安装 [Claude Code](https://claude.ai/code)
- 网络连接（分析过程中需抓取公开财务数据）
- Python 3.x（用于 `check_citations.py` 校验脚本）

### 安装

```bash
# 克隆项目
git clone git@github.com:BigDaddy118/A-share-investment-system.git

# 进入项目目录
cd A-share-investment-system
```

### 使用

在 Claude Code 中打开项目目录后，直接输入斜杠命令：

```bash
# 分析新标的
/投资决策 600030

# 复查已持有标的
/审视持仓 600030

# 诊断整个组合
/组合诊断
```

## 分析流程

```
用户: /投资决策 600030
  │
  ├─ Step 0: 判断成分股归属 → 确定可分析深度
  │
  ├─ Step 1: 6 个 Agent 并行分析
  │   ├── 财报分析 → 01_财报分析.md
  │   ├── 商业分析 → 02_商业分析.md
  │   ├── 估值分析 → 03_估值分析.md
  │   ├── 催化剂分析 → 04_催化剂分析.md
  │   ├── 技术分析 → 05_技术分析.md
  │   └── 资金面分析 → 06_资金面分析.md
  │
  ├─ Step 2: 读取6份报告 → 数据完整度评分
  ├─ Step 3: 提炼变异认知（市场共识 vs 我们的不同看法）
  ├─ Step 4: 概率加权 → 仓位建议
  ├─ Step 5: 制定操作计划
  └─ Step 6: 输出 00_投资决策.md
       └─ 运行 check_citations.py 校验引用
```

## 投资方法论

1. **变异认知驱动**：每笔投资必须找到"市场共识 vs 我们不同看法"
2. **概率加权仓位**：仓位由确信度 × 安全边际决定
3. **论据可推翻**：每笔投资预定义清仓条件
4. **分批建仓**：分 2-3 批在催化剂验证后逐步加仓

## 引用标准

所有报告采用学术论文级引用规范：每个数据点标注 `[n]`，参考文献均为可点击的 `[文档名](URL)` 超链接。报告生成后自动运行 `check_citations.py` 校验。
