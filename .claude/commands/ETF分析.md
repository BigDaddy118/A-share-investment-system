调用4个分析skill（指数分析/估值分析/技术分析/资金面分析），读取报告，交叉验证，形成变异认知，输出概率加权的ETF投资建议。

## 输入
ETF代码（如 510300）

## 执行

### Step 0：判断ETF类型
- 确定ETF简称和全称（通过搜索ETF代码）
- 判断ETF类型：宽基 / 行业 / 主题 / 策略 / 跨境 / 债券 / 商品
- 确定跟踪指数及代码
- 创建输出文件夹：`分析记录/{ETF简称}_{代码}/`

### Step 1：并行调用4个分析skill
使用 Agent 工具并行启动4个分析agent，每个agent读取对应的skill定义文件（`skills/` 目录下）并严格执行。每个agent将报告写入对应路径。

| Agent | Skill文件 | 输出文件 |
|-------|----------|----------|
| 指数分析 | skills/指数分析.md | 01_指数分析.md |
| ETF估值分析 | skills/ETF估值分析.md | 02_ETF估值分析.md |
| 技术分析 | skills/技术分析.md | 03_技术分析.md |
| ETF资金面分析 | skills/ETF资金面分析.md | 04_ETF资金面分析.md |

### Step 2：读取报告 + 数据完整度评分
- 读取全部4份报告
- 汇总哪些维度完整、哪些标注了"不适用"
- 评分：完整 / 基本完整 / 部分缺失 / 严重缺失

### Step 3：提炼变异认知
- 从4份报告中提取市场共识 vs 我们的不同看法（至少一个）
- 引用具体数据作为证据
- 找不到变异认知 → 写"不建议买入"

### Step 4：估值分位 + 资金方向 → 仓位建议
ETF仓位逻辑：**看估值分位+资金方向+ETF类型**。

**类型基准仓位：**
- 宽基ETF：≤20% | 行业ETF：≤10% | 主题ETF：≤5%
- 跨境ETF：≤15% | 债券ETF：≤15% | 商品ETF：≤5%

**估值分位调整：**
- <20% → ×1.2~1.5 | 20-40% → ×1.0~1.2 | 40-60% → ×1.0
- 60-80% → ×0.5~0.8 | 80-90% → ×0.3~0.5 | >90% → 不买

**资金方向微调：**
- 份额增长+溢价 → +10% | 份额缩减+折价 → -10%
- 份额缩减+净值涨 → -15%（出货信号）

### Step 5：制定操作计划
- 判断当前是否可买、什么价格区间
- ETF优先考虑定投策略
- 估值分位<20% → 可一次性买入50%目标仓位，剩余分批
- 估值分位20-50% → 标准定投，分3-6期
- 估值分位>50% → 等待更好时机

### Step 6：写完整决策报告
写入 `分析记录/{ETF简称}_{代码}/00_ETF决策.md`，参考 `skills/ETF分析.md` 中的输出格式。必须包含：数据完整度评分、四维度核心发现汇总、变异认知、仓位建议、操作计划（含定投策略）、论据推翻条件、风险提示。

## 关键规则
- **技术分析直接复用个股skill**：`skills/技术分析.md` 对ETF同样适用
- **ETF估值看分位不看绝对值**：PE低≠便宜（可能盈利差），PE高≠贵（可能盈利好），分位才有意义
- **资金面核心看份额**：份额变化比成交额更重要，是ETF的"聪明钱"指标
- **跨境ETF关注溢价率**：溢价>2%需警惕，可能是QDII额度紧张导致
