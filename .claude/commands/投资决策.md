调用全部6个分析skill并行执行，读取报告，交叉验证，形成变异认知，输出概率加权的投资建议。

## 输入
股票代码（如 600030）

## 执行

### Step 0：宏观环境确认 + 判断可分析深度
- **先读取 `分析记录/宏观环境诊断.md`**（如存在），确认当前宏观象限和行业偏好
- 该标的所处行业是否为宏观环境偏好的方向？宏观逆风时仓位上限下调
- 确定公司简称（通过搜索股票代码）
- 判断成分股归属：沪深300 / 中证500 / 其他
- 确定每个分析维度的可用数据范围
- 创建输出文件夹：`分析记录/{公司简称}_{股票代码}/`

### Step 1：并行调用6个分析skill
使用 Agent 工具并行启动6个分析agent，每个agent读取对应的skill定义文件（`skills/` 目录下）并严格执行。每个agent将报告写入 `分析记录/{公司简称}_{股票代码}/` 对应路径。

| Agent | Skill文件 | 输出文件 |
|-------|----------|----------|
| 财报分析 | skills/财报分析.md | 01_财报分析.md |
| 商业分析 | skills/商业分析.md | 02_商业分析.md |
| 估值分析 | skills/估值分析.md | 03_估值分析.md |
| 催化剂分析 | skills/催化剂分析.md | 04_催化剂分析.md |
| 技术分析 | skills/技术分析.md | 05_技术分析.md |
| 资金面分析 | skills/资金面分析.md | 06_资金面分析.md |

### Step 2：读取报告 + 数据完整度评分
- 读取全部6份报告
- 汇总哪些维度完整、哪些标注了"不适用"
- 评分：完整 / 基本完整 / 部分缺失 / 严重缺失

### Step 3：提炼变异认知
- 从6份报告中提取市场共识 vs 我们的不同看法（至少一个）
- 引用具体数据作为证据
- 找不到变异认知 → 写"不建议买入"

### Step 4：概率加权 → 仓位建议

确信度分级：
- 高确信：变异认知清晰 + 证据充分 + 数据完整
- 中确信：变异认知存在 + 证据部分支持
- 低确信：变异认知模糊 + 证据不足

| 确信 × 安全边际 | 仓位建议 |
|------|------|
| 高确信 + 安全边际大 + 催化剂临近 | 重仓（15-25%） |
| 高确信 + 安全边际大 + 催化剂较远 | 标准偏重（10-15%） |
| 高确信 + 安全边际一般 | 标准仓（8-12%） |
| 中确信 + 安全边际大 | 中等仓（5-8%） |
| 中确信 + 安全边际一般 | 观察仓（3-5%） |
| 低确信 或 安全边际不足 | 不买 |

数据缺失 → 确信度下调一档。
宏观环境对该行业不利 → 仓位上限降一档；宏观对该行业有利 → 仓位可触及上限。

### Step 5：制定操作计划
- 判断当前是否可买
- 分几批、什么条件、什么价格区间
- 如果等，等什么信号

### Step 6：写完整决策报告
写入 `分析记录/{公司简称}_{股票代码}/00_投资决策.md`，参考 `skills/投资决策.md` 中的输出格式。必须包含：数据完整度评分、六维度核心发现汇总、变异认知、仓位建议、分批建仓计划、论据推翻/减仓条件、压力测试。

## 关键规则
- **必须使用真实财务数据**：财报分析agent要用curl抓取新浪财经/东方财富的实际年报数据（注意GB2312→UTF-8编码转换），禁止使用估算值
- **数据缺失要标注**：某维度数据不可得时，标注原因并下调确信度
- **报告用中文**：所有输出文件内容必须为中文
